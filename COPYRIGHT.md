## Original Work

Markdraft began as a fork of [Grip](https://github.com/joeyespo/grip)
by Joe Esposito (Copyright (c) 2014-2022, MIT License). Grip's reader
abstractions and CLI design informed markdraft's early architecture.

The codebase has since been entirely rewritten: first as a Python
project replacing Flask with stdlib http.server and moving to
client-side rendering, then ported to TypeScript/Node.js. No
substantial original Grip code remains.
